Controls scancode labels on the keymap and in scancode dropdowns. This is an Agent setting and is not saved to the keyboard. Choose the layout that matches your keycaps (US, UK, German, or Nordic).

AI clients on this computer, such as Claude Code or Codex, can read your keymaps, macros and settings, and propose changes to them.

Proposed changes wait in Agent. They reach the keyboard when you click Save to keyboard, unless you let AI clients save. Access continues while Agent is in the system tray.

When off, AI clients see only the length of text macros. Leave it off if a text macro holds a password. Smart-macro commands are always visible, including text typed by write.

AI clients can save without a click in Agent, and Agent shows a notice after each save. Leave it off to review every change before it reaches the keyboard.

You still need to save these yourself: macros that run without a key press, macros that they call, launcher or shell shortcuts Agent recognizes, and changes that could lock you out.

Regenerating the token or turning AI access off turns this off.

Agent listens on this port, on this computer only. After you change it, update the connection in your AI client.

The Follow operating system theme option may not be supported on all Linux distributions.

On Linux, disabling this option stops minimize-to-tray behaviour immediately, but the tray icon may remain visible until Agent is restarted.
